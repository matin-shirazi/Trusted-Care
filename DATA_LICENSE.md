# Data licensing

The MIT license in [`LICENSE`](LICENSE) covers the code. The data files in this repository are covered as follows.

## Synthetic data created by this project (MIT)

`data/customers_FAKE.json` and `data/dialogues.jsonl` (and the other synthetic customers, dialogues and audit records
generated by the code) are created by this project. All customer records are fake (ids start with `FAKE`, e-mail
addresses end in `.invalid`). They are covered by the same MIT license as the code.

## Third-party data: `data/external/attack_texts.jsonl` (MIT)

`data/external/attack_texts.jsonl` is a copy of the Hugging Face dataset
[`smd20/social-engineering-attack-texts-persian`](https://huggingface.co/datasets/smd20/social-engineering-attack-texts-persian)
(246 Persian social-engineering attack texts; dataset curator: Samad Sohrab).

- License: MIT (as declared in the dataset card on Hugging Face).
- The texts were generated by a language model from the `smd20/social-engineering-qa-persian` Q&A dataset, whose
  original content remains the property of its respective creators (see the dataset card).
- It is used here only as an extra held-out attack-only test set; it is not modified.
- If you use it in research, the dataset card asks you to cite:
  Sohrab, S. (2026). *Social Engineering Attack Classification in Persian Text*.
  https://github.com/s-sohrab/social-engineering-ml
